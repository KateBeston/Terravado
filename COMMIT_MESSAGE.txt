Main site: keep only user-facing sections; internal-only stays portal-only

Clarifies the two-app split. The INTERNAL PORTAL stays fully intact (unchanged) —
it remains the complete operational view of Terravado. The MAIN SITE carries only
what a user (adviser / broker / consultant / client) would want; Terravado-internal
sections were removed from it.

Removed from apps/main-site (portal keeps all of these)
- Admin console (platform-admin / tenant management)
- Data Sources (managing + logging the data feeds)
- The Business (Terravado's own business documents)
- Integrations (redirect into Data Sources)
- /api/regwatch cron route (the fortnightly ingestion job) + its vercel.json cron
- Nav: dropped the Data Sources, The Business and Admin links; sidebar no longer
  labelled "Internal Portal"

Kept on apps/main-site (user-facing)
- Dashboard, Modeller/Workspace, Lenders, Portfolio, Equity chain, Contacts,
  Entities, Properties, Atlas, Stock, Match, Shortlist, Feasibility, Pipeline,
  Finance, Lodgements, Regulatory Watch, Shared-with-me, Account, Deal export,
  invite acceptance, and the clients/companies/map redirects.

Regulatory Watch — split
- The alerts VIEW stays on the main site (advisers benefit from seeing tax /
  lending / property-law changes — read + mark-read only).
- The INGESTION stays internal: removed the "Check now" trigger and the internal
  config note from the main-site page; the fortnightly cron lives only in the portal.
